# Mylo Products

A small products app on the [Platzi Fake Store API](https://api.escuelajs.co/api/v1): login, paged products, detail, and create / edit / delete, with a hand-built physics swipe deck.

> Work in progress. Sections marked _TODO_ are filled in as the stages land.

## Setup

Requirements: Flutter 3.47.0 (see `.fvmrc`), Xcode (iOS) or Android SDK.

```bash
flutter pub get
flutter run
```

Test user: `john@mail.com` / `changeme`.

Checks (analyze + all package tests): `tool/check.sh`.
Widget previews: `flutter widget-preview start`.
